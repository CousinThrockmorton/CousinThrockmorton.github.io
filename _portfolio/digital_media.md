I worked as a teaching assistant to create a set of python notebook companions for a couple chapters of the book by Couldry, Nick, and Jose Van Dijck. "Researching social media as if the social mattered". All the notebooks and code can be found on the [Repo](https://github.com/maxigas/Researching-Digital-Media-and-Society)

The repo is relevant to chapter 7 Text analysis, 8 Network analysis and 9 Visual analysis. First, I created a notebook that recreating the analysis in the Text Analysis chapter analysing a Trump tweet dataset off Kaggle. Then, I created a markdown guide for using Gephi and creating the visuals presented in the book. For the last chapter I made two notebooks for creating meta-images from search queries. And a notebook for pulling key-frames from some videos to create a collage.
